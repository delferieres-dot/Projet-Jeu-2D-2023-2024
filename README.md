# 🎮 Projet de Jeu Vidéo 2D en C#

Jeu vidéo 2D développé en C# (Windows Forms / .NET) dans le cadre du projet de programmation (2023-2024).

---

## 🚀 À propos du projet
Ce projet consiste en la conception et le développement d'un jeu de plateforme/action 2D en C#. Il met en œuvre les principes de la programmation orientée objet, la gestion des mouvements, des collisions, des niveaux multiples et des interfaces de jeu (menus, scores, états).

## 🛠️ Technologies & Outils
* **Langage :** C# (.NET)
* **Architecture :** Modèle-Vue-Contrôleur (MVC) / Orienté Objet
* **Environnement :** Visual Studio

## 📁 Structure du dépôt
* `ProjetProgrammation5.0/` : Code source complet du jeu (scripts, formulaires, ressources graphiques).
* `Rapport projet laboratoire Q2 Programmation 2023-2024.pdf` : Rapport technique détaillé du projet.
